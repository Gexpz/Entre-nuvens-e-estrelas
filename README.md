*Entre Nuvens e Estrelas☁️🐼*

*Descrição:*

Entre Nuvens e Estrelas é um jogo desenvolvido em Python com Pygame como projeto acadêmico. O jogador controla um panda que precisa desviar de nuvens enquanto avança pelo céu, utilizando bônus para superar os obstáculos e alcançar a vitória.

🎮 *Como jogar:*

Use as teclas ← → para movimentar o panda.

Desvie das nuvens.

Colete os bônus para obter vantagens.

Sobreviva até completar o objetivo do jogo.

🛠️ *Tecnologias:*

-Python

-Pygame

📖 *Sobre o projeto:*

O projeto foi desenvolvido como uma experiência prática de programação, explorando conceitos de lógica, estruturas de repetição, condições, eventos, colisões, movimentação e criação de uma interface interativa com Pygame.

📝 *O que aprendi:*

Durante o desenvolvimento, pratiquei a criação de mecânicas de jogo, gerenciamento de eventos, detecção de colisões e organização de recursos visuais, além de desenvolver minha capacidade de transformar uma ideia em uma experiência interativa.
